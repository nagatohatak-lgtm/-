🎭 Random Quote Generator
Генератор случайных цитат с графическим интерфейсом, историей и фильтрацией. Проект создан для изучения Python, Tkinter и работы с файлами JSON.

🚀 Возможности
Генерация: Получай случайную цитату из встроенной базы одним нажатием кнопки.
История: Все сгенерированные цитаты сохраняются в список и не пропадают после перезапуска программы.
Фильтрация: Ищи нужные цитаты в истории по автору или теме.
Расширение: Добавляй свои собственные цитаты в общую базу данных.
Сохранение: История сохраняется в файл history.json.
🛠️ Технологии
Язык: Python 3.
GUI: Библиотека Tkinter.
Данные: Формат JSON.
📁 Структура проекта
В папке проекта находятся следующие файлы:
main.py — основной файл с кодом приложения и графическим интерфейсом.
quotes.py — файл со списком предопределённых цитат.
history.json — файл, в котором хранится история сгенерированных цитат (создаётся автоматически).
.gitignore — файл для исключения history.json из системы контроля версий.
🐍 Как запустить
Открой терминал (командную строку) в папке с проектом.
Запусти команду:
bash
Копировать
python main.py
👩‍💻 Как добавить свою цитату
Запусти приложение.
Перейди на вкладку «Добавить цитату».
Введи текст цитаты, имя автора и тему в соответствующие поля.
Нажми кнопку «Добавить цитату в базу».
Ваша цитата будет добавлена в общую базу и сможет быть сгенерирована в будущем.

🗃️ Контроль версий
Проект управляется с помощью Git. Файл history.json добавлен в .gitignore, чтобы ваши личные данные об истории просмотров не попадали в удалённый репозиторий.
